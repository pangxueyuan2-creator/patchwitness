# GitHub Discussion draft

## Title

Welcome to PatchWitness: what should a trustworthy Change Passport prove next?

## Body

PatchWitness v0.1.0 establishes a deterministic core for scope, protected surfaces, checks, secrets,
impact, and portable evidence. The next priorities should be driven by real repositories.

If you try it, please share:

1. repository language/build system;
2. coding agent or human workflow;
3. which finding was useful or noisy;
4. which evidence was missing from review;
5. whether you would prefer a plugin, core rule, or CI adapter.

Please never paste private source, credentials, or sensitive evidence into a public discussion.
