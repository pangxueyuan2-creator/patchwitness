## Addition criteria

Add a record only if it has a direct public URL and a precise description of the author, relevant statement and evidence level. A positive reaction, generic directory listing, reposted maintainer message, crawler index or link without substantive context remains discovery data, not an independent recommendation. If authorship is unclear, classify it as `UNKNOWN`.
