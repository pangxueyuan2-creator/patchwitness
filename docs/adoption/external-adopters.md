# External Adopters

**Current verified external adopters: 0.**

This ledger records only real, externally controlled repository trials and integrations that are public or explicitly permissioned. Maintainer-owned example repositories, CI runs inside this repository, release-download aggregates, private conversations and unverified claims are not external adopters.

## Acceptance criteria

| Evidence level | What can be recorded | Required proof |
|---:|---|---|
| 2 | Non-maintainer reproduced the public Demo | Public Trial Report, Issue or discussion with distinct author and command/result summary |
| 3 | Non-maintainer ran PatchWitness on their repository | Public repository/workflow URL or explicit permission plus sanitized repository shape and actual result |
| 4 | Non-maintainer submitted actionable Trial Report / Issue | Public URL, author and feedback summary; privacy choice honored |
| 5 | External repository has optional workflow | Public workflow, PR, config or direct maintainer statement |
| 6 | External repository uses recommended or required CI gate | Public workflow, branch-protection context, README/docs or direct maintainer statement |
| 9 | Multiple projects continue use over time | Multiple verified records, each with its own evidence |

An external repository is never labelled a customer. A short evaluation is a **trial**. Do not quote a maintainer or name an organization as an endorser without explicit permission.

## Privacy and revocation

A public repository link may be recorded only if the source itself is public and relevant. For non-public trials, store no project name, source code, credential, proprietary log or sensitive Change Passport in this file. If a reporter withdraws permission, remove or anonymize the record promptly while retaining only aggregate, non-identifying evidence if allowed.
